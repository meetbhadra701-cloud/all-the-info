# REPRODUCTION — Wave 10

Every experiment runs inside `openroad/orfs:latest` (the local image, 2026-09-19) with `--network none`, driven from WSL `Ubuntu-26.04` through Docker Desktop. Third-party code is never executed on the Windows host. No LLM API is called anywhere.

Host facts:
- **CPU:** Intel Core Ultra 7 258V (no AVX-512).
- **Container toolchain:** gcc 11.4.0, cmake 3.31.9, Python 3.10.12 + numpy 2.2.6.
- **Tools:** Yosys 0.68+post and yosys-abc (ABC 1.01), from `/OpenROAD-flow-scripts/tools/install/yosys/bin`.

Shell convention: from Git Bash, call WSL with `MSYS_NO_PATHCONV=1` and pass script *files*, never inline `$VARS`.

```bash
MSYS_NO_PATHCONV=1 wsl.exe -d Ubuntu-26.04 -- bash /mnt/c/Users/meetb/Desktop/CLAUDE_OPUS_5_5_RESEARCH_CONTEXT/12_WAVE_10_EXPERIMENTAL_DISCOVERY/experiments/scripts/<script>.sh [args]
```

## 1. C1 build

The builds use `experiments/scripts/c1/CMakeLists.txt`, `c1_driver.cpp` and `c1_emap.cpp`.

```bash
# 4 operator variants x {unmodified main.cpp, driver} + emap driver
bash experiments/scripts/c1_build.sh
# D2 ablation drivers (sources generated by d2_make_ablations.py)
python experiments/scripts/c1/d2_make_ablations.py
bash experiments/scripts/c1_build_ablation.sh
```

Binaries go to `experiments/outputs/c1/bin/`. Source and binary MD5s are in `MANIFEST.txt` and `MANIFEST_ablation.txt`.

The runtime wrapper is `experiments/scripts/c1_docker.sh <inner script> [args]`. It recreates `/tmp/c1src/third-party/mockturtle` inside the container, because main.cpp's `EXPERIMENTS_PATH` is compiled in.

## 3. Verdict rules (fail-closed)

- **CEC:** only the literal line "Networks are equivalent" counts as PASS. `NOT EQUIVALENT` counts as NEQ. Anything else, including a timeout, counts as UNDECIDED. Process exit codes are never read as verdicts.
- **Simulation:** `SIM_MISMATCH` (with a counterexample) refutes a netlist. `SIM_AGREE` is not a proof.
- **Pre-registration:** `experiments/results/c1_PREREGISTRATION.md`, including a timestamped deviation log. C6: `experiments/results/c6_PREREGISTRATION.md`.
