# Experiment Index

No PPA-Delta EDA experiments have been completed at starter-pack delivery.

The agents create one uniquely named experiment note after each meaningful completed or failed run. Raw records go in `runs/<agent>/<run-id>/` outside the vault. [[Project-Status]] lists recent notes; the Experiments subfolders retain the history.

Every record must identify source/config/tool/library hashes, exact command, semantic contract, budget, formal status, area values and units, thresholds, size metrics, failures, result location and interpretation. A synthetic example is labeled synthetic. A mocked evaluator test is never a real benchmark result.

Use [[09-Templates/Experiment-Note]]. A later summary must enumerate the full frozen case set rather than only successful cases.
