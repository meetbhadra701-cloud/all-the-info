# Start PPA-Delta

For normal use, begin with [README.md](README.md): install the local wheel or
editable checkout, point `PPA_DELTA_EDA_ROOT` at OSS CAD Suite 20260816, run
`ppa-delta doctor`, then replay one of the immutable bundles.

For project review:

- `analysis/month-one-report.md` contains the machine-derived ten-pair result;
- `docs/codex/release-candidate.md` explains the release and clean replay;
- `docs/codex/supported-subset.md` states the exact language boundary;
- `Obsidian-Vault/Project-Status.md` is the generated coordination dashboard;
- `CODEX-MANUAL.md` and `CLAUDE-MANUAL.md` preserve the two-agent protocol.

Open this repository's `Obsidian-Vault/` directory as an Obsidian folder vault
if you want the full experiment journal. The user does not need to edit it.

All model work is performed inline by the two user-started peers. The local
release candidate is unpublished, uses no Docker or model API at runtime, and
does not authorize month-two work or external outreach.
